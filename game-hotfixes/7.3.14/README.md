# Deutscher Text-Hotfix 7.3.14

Enthält ausschließlich `patch/Mods/zzzzGermanGrammarAndClub.rb` als Ergänzung für AllGen Reborn 0.9.9. 202 Namens-/Grammatikkorrekturen und 1.158 Club-Dialogfelder; UI und Kampflogik bleiben unverändert.

Das automatische V2-Delta aktualisiert Spielversion 7.3.13 mit Launcher 7.4.0. Installation und Versionswechsel werden mit dem tatsächlichen UpdateService an isolierten Testdaten geprüft. Frühere Spielversionen verwenden das vollständige Fallbackpaket. Der Launcher selbst bleibt auf 7.4.0.

Manuell: `Reborn-7.3.14-Zusatzdateien.zip` bei geschlossenem Spiel in den Spielordner entpacken. Eine bereits manuell installierte Datei gleichen Namens vor einem automatischen Delta-Update außerhalb des Spielordners sichern; der Launcher überschreibt unbekannte vorhandene Mod-Dateien absichtlich nicht.

Rückweg bei manueller Installation: die Mod-Datei entfernen und neu starten. Automatische Installation: Versionswechsel im Launcher. Originaldaten und Spielstände werden von der Mod nicht geschrieben.

Prüfprotokolle beschreiben die tatsächlich ausgeführten Ruby- und Paketprüfungen. Kein vollständiger grafischer Spieldurchlauf.
