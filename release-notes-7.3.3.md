# Launcher 7.3.3 - Kleine automatische Spiel-Hotfixes

Der Launcher kann passende Spiel-Hotfixes jetzt als kleines Paket mit ausschliesslich geaenderten Dateien installieren. Fuer den Fang-Fix von Spielversion 7.3.1 auf 7.3.2 sind das 4.190 Bytes statt des gesamten Spielpakets.

Vor der Auswahl werden installierte Version und Ausgangsdateien geprueft. Bei einer anderen Ausgangsversion, veraenderten Ausgangsdateien oder einer Reparatur wird das vollstaendige Spielpaket verwendet. Downloads und enthaltene Dateien werden per SHA-256 verifiziert. Sicherung, Wiederherstellung und Versionswechsel bleiben erhalten.

Einmalig wird dieser Launcher selbst aktualisiert. Danach erfolgt die Auswahl des passenden Spielpakets automatisch. Bestehende Launcher koennen weiterhin das vollstaendige Spielupdate installieren.

Die Oberflaeche entspricht dem veroeffentlichten Launcher 7.3.0; laufende Designarbeiten sind nicht Teil dieses Service-Updates.
