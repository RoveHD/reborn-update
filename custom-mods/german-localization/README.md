# Gemeinsame deutsche Lokalisierung

Alle künftigen deutschen Text-, Grammatik-, Sprecher-, Item-, Straßen- und Etagenkorrekturen in `patch/Mods/RE_Deutsch.rb` einpflegen. Keine weiteren separaten Übersetzungsmods hinzufügen. Die Datei enthält auch die Sprachauswahl. Der ScriptLoader erhält die benötigte Ladeposition unabhängig vom Dateinamen.

Der Launcher migriert bekannte Vorgängerdateien per Prüfsumme; die konsolidierte Datei nicht zusätzlich neben alten Komponenten manuell installieren.
