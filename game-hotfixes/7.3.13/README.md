# Byteon-Entwicklungs-Hotfix 7.3.13

Kleines automatisches Delta für Launcher 7.4.0 sowie manuelles Zusatzpaket für AllGen Reborn 0.9.9 / Spielpaket 7.3.12. Es ergänzt ausschließlich die fehlende Evoli-zu-Byteon-Verknüpfung als eigene Mod-Datei. Byteons Werte, Fähigkeiten und Attacken werden nicht verändert. Ältere Launcher verwenden weiter das vollständige Fallbackpaket.

## Installation

Spiel vollständig schließen, den vorhandenen Spielordner sichern und `Reborn-7.3.13-Zusatzdateien.zip` direkt in den Spielordner entpacken. Dabei entsteht `patch/Mods/zzzzByteonEvolutionHotfix.rb`. Danach das Spiel neu starten. Die Entwicklung wird bei einem Levelaufstieg in den vorhandenen Byteon-Glitch-Gebieten geprüft. Everstone/Eviolite, Eeveetite/Eevium Z sowie eine gesperrte Evoli-Form verhindern sie weiterhin wie vorgesehen.

Das Delta enthält nur diese additive Datei; Spielstände und Einstellungen bleiben unberührt. Der Launcher sichert die vorherige Version. Beim Zurückwechseln wird die neue Datei wieder entfernt; vorhandene Dateien und Mods bleiben erhalten.
