# Launcher 7.4.1

- Spielupdates und Reparaturen lassen sich jetzt auch starten, wenn „Vorherige“ als Spielversion ausgewählt ist.
- Das Update führt von der gerade ausgewählten Version auf den aktuellen Kanalstand. Die vorige Version bleibt als Rückweg erhalten.
- Automatische Spielupdates bleiben pausiert, solange du bewusst die vorige Version spielst. Manuelle Updates und Launcher-Selbstupdates sind weiterhin verfügbar.
- Spielstände und persönliche Einstellungen bleiben erhalten.
- Der Spielkanal bleibt unverändert auf Pokémon Reborn AllGen 0.9.9, Version 7.3.25.
